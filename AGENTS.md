# Regras para o Codex (ChatGPT) neste repositório

Leia também o `CLAUDE.md`: as regras do projeto Félix valem para todas as IAs.

## Skynet Chat — proibido (desde 06/11/2026, ordem do Leandro)
- Nenhuma relação com o Skynet Chat (skynetchat.net / Shapes): nada de rotina, tarefa, pendência, extensão do Chrome, ponte local, túnel, espelho ou cérebro ligado a ele.
- Se houver no Mac alguma rotina, extensão ("Janete Skynet") ou túnel criado para o Skynet, desligue e apague.
- A Janete antiga foi excluída do site em 08/11/2026 (ordem do Leandro). Em 10/11/2026 o Leandro pediu uma nova Janete em /janete (janete/index.html: página da assistente com demonstração). Não recriar /janete-lite. O janete/sw.js e o janete-lite/sw.js continuam só para limpar aparelhos que tinham a Janete antiga instalada; a página nova não registra service worker.
